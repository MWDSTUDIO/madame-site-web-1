Bienvenue dans L'Atelier

Cette application te permet d'ajouter ou de modifier un mariage — avec ses deux volets, Portfolio (la galerie) et Journal (le récit + la presse) — sans toucher au code. Elle écrit directement dans le dossier du site sur ton ordinateur.

  1. Clique sur « Ouvrir le dossier du site » et choisis le dossier du projet (celui qui contient index.html).
  2. Ajoute ou modifie tes mariages, dépose les photos, écris le récit.
  3. Clique sur « Enregistrer » : les photos sont copiées, les pages créées, les données mises à jour.
  4. Re-glisse le dossier sur Netlify (ou git push) pour publier.

Ton navigateur ne permet pas l'écriture de fichiers locaux. Utilise Chrome ou Edge sur ordinateur pour L'Atelier.
